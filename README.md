# Kenneth Jaramilla — Portfolio

Personal portfolio for **Kenneth Jaramilla**, Senior Full Stack Developer & Certified Scrum Master.

Single-page, responsive, dark-themed site built from scratch in **vanilla HTML, CSS & JS** —
no framework, no build step. Fast, accessible, and deployable as a static site.

## Sections
Hero · About · Skills · Experience · Projects (enterprise + open-source) · Building with AI · Contact

## Run locally
Open `index.html` in a browser, or:
```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Deploy
Static site — deploys to Vercel as-is (no build command). `index.html` at the repo root.

## Structure
- `index.html` — the whole site (inline CSS + JS)
- `assets/` — avatar, favicon
- `Kenneth-Jaramilla-Resume.pdf` — downloadable résumé
